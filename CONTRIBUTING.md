# Contributing

Приветствуются любые предложения, улучшения и исправления ошибок в проекте Gemini Edge Gateway!

## Порядок предложения изменений

1. Создайте форк (Fork) репозитория
2. Создайте новую ветку для ваших изменений
3. Внесите изменения и протестируйте их
4. Закоммитьте изменения в соответствии с правилами формата коммитов
5. Отправьте ветку в ваш форк (`git push origin feature/my-new-feature`) и создайте Pull Request в ветку `main`

## Формат сообщений коммитов (Conventional Commits)

Все коммиты должны следовать спецификации Conventional Commits:
```
<type>(<scope>): <description>
```
